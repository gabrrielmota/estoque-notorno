
# Almoxarifado e Usuários

**Aluno(a):** Gabriel Mota Antunes Ferreira

**Turma:** Técnico em Desenv. de Sistemas - Noturno

## Descrição

Projeto desenvolvido em Python para gerenciar produtos, estoque, usuários, papéis e permissões de acesso.

## Organização das pastas

- **produtos/**: contém as classes Produto e Almoxarifado.
- **usuarios/**: contém os papéis, permissões e a classe Usuario.
- **testes/**: contém os arquivos de testes do projeto.

## Como executar os testes

No terminal, dentro da pasta principal do projeto, execute:

`py -m testes.teste_almoxarifado`

`py -m testes.teste_usuario`
