
# Almoxarifado

**Aluno(a):** Gabriel Mota Antunes Ferreira

**Turma:** Técnico em Desenv. de Sistemas - Noturno

## Descrição

Projeto desenvolvido em Python para gerenciar o estoque de um almoxarifado, permitindo cadastrar produtos, consultar quantidades, registrar entradas e saídas e calcular o valor total do estoque. Também permite gerenciar usuários, seus papéis, permissões de acesso, autenticação e controle de sessões.

## Organização das pastas

- **produtos/**: contém os arquivos responsáveis pelo cadastro e gerenciamento dos produtos e do estoque.
- **usuarios/**: contém os arquivos responsáveis pelos papéis, permissões, gerenciamento dos usuários e controle de acesso.
- **testes/**: contém os arquivos utilizados para testar as funcionalidades do sistema.

## Como executar os testes

No terminal, execute os comandos:

`py -m testes.teste_almoxarifado`

`py -m testes.teste_usuario`

`py -m testes.teste_controle_acesso`
